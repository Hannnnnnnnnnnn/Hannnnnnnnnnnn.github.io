## 1. 진짜 문제는 노출 수가 아니라 곱셈이었다

질문은 "노출/클릭을 공개해도 되냐"였는데, 페이지를 실제로 계산해보니 더 아래에 있었다.
케이스는 **클라이언트를 실명으로** 밝히고(`Client Atacz`) 사이트는 공개다. 그 상태에서
같은 페이지에 **세션 수와 전환율이 나란히** 있었다.

    세션 수 × 전환율 = 주문 수
    주문 수 × AOV(Decision 03 데모의 실제 가격표) = 연 매출 추정

오차는 있어도 자릿수는 고정된다. **비상장 회사 매출 규모는 내가 공개할 권한이 있는
정보가 아니다.** work-2 의 방문 수까지 합치면 트래픽 규모가 교차 검증돼 정밀도가 더 오른다.

민감도 순위를 내고 오너가 항목별로 판단했다:

| 등급 | 항목 | 판단 |
|---|---|---|
| 높음 | 세션 수 + 전환율 절대값 | **세션 수 삭제** (곱셈의 한쪽 다리) |
| 높음 | Bind Strap 판매 수량, 판매량 톱5 | **수량 삭제**, 톱5는 유지 |
| 중간 | Shop Pay / BNPL 결제 비중 | **유지** — 오너 판단 |
| 중간 | 장바구니 완료율 20.8% → 25.3% | **유지** — 오너 판단 |
| 낮음 | GSC 노출·클릭 절대값 | **삭제** (원래 질문) |
| 낮음 | 모든 퍼센트·델타 | **전부 유지** |

## 2. 곱셈은 한쪽 다리만 끊으면 된다

역산은 `세션 × 전환율`이라 **둘 중 하나만 없애도 성립하지 않는다.** 손해가 적은 쪽은
세션 수였다 — 딱 한 군데(Outcome 의 단서 문단)에만 나오고, 그 문단이 하려던 말은
"두 구간의 볼륨이 달랐다"는 정직성 고백이지 숫자 자체가 아니었다.

    (세션 수 두 개)  →  (the after period ran about 12% lighter)

**부수 효과로 문장이 나아졌다.** 원래는 독자가 두 숫자를 직접 나눠야 방향을 알 수 있었다.
바꾸고 나니 "트래픽이 **적은** 구간에서 나온 개선"이라는, 결과를 강하게 만드는 사실이
바로 읽힌다. 전환율은 손대지 않았으므로 정직성 지표는 그대로다.

같은 원리로 나머지도 **주장은 남기고 수치만** 뺐다:

| 위치 | 처리 |
|---|---|
| §1 도입부 | 노출·클릭 절대값 삭제 → "Search demand was not the problem. Over four months of Search Console data…" + **1.0–1.7% CTR 유지** |
| §1 표 | Product / Impressions / Clicks / CTR → **Product / CTR** 2열 |
| §2 리서치 | "had sold N units unprompted" → "had become a **top-five seller by volume** entirely unprompted" |
| Decision 03 | "sold N units with zero on-page prompting" → "was a top-five seller by volume with…" |

성과 지표(+33% CTR, −53% 데드클릭, +23% 전환, +51% 스크롤)는 **한 글자도 안 건드렸다.**
포트폴리오에서 실력을 보여주는 건 어차피 변화량이지 절대값이 아니다.

### 내가 혼자 판단한 것 1건

`Over four months` 라는 **기간 표현은 남겼다.** 오너 지시는 "4개월 단위를 지우자"였고
문자 그대로면 기간까지 포함될 수 있었다. 숫자 빠진 기간은 새는 게 없고 "일시적 현상이
아니라 4개월 지속된 패턴"이라는 근거는 살리는 게 낫다고 봤다 — **판단 후 바로 밝히고
되돌릴 수 있게 했다.** 오너가 이의 없이 다음으로 넘어갔다.
